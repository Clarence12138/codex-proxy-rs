# Portal 用户面板

拼车用户控制面平行于管理员，不改变 `/v1` 协议。HTTP 字段见 [接口文档](api.md#portal-用户面板)。

- 用户面：`/portal`、`/api/portal/*`，Cookie `cpr_portal_session`
- 管理面仍为 `/` 与 `/api/admin/*`；用户/套餐管理在 `/portal-users`、`/portal-plans`
- 密钥仍是 `client_api_keys`，请求仍是 `model_requests`（冻结 `owner_user_id`）
- 日/周 USD 与并发/RPM 按用户合计，同时受 Key 自身限额约束
- 概览只有在订阅状态/时间有效且套餐启用时显示生效；个人成功用量复用网关完整交付口径，排除预热、失败和无用量证据的请求
- 成功用量汇总与日/周预算账本用途不同：账本仍累计重试等实际取得的费用，不以成功用量汇总代替额度结算
- 用户 Key 禁止无分组（空池，不回退全部账号）
- 用户只禁用不物理删除；改密和停用会在同一事务里撤销会话
- 普通用户密码至少 6 个字符、最多 256 个 UTF-8 字节；允许纯数字、纯字母和 `$`，无需字符组合，不去除首尾空格；系统管理员初始化密码策略不变
- 管理员创建用户时自动填入随机的 8 位字母数字初始密码，可显示、隐藏、复制或手动修改；创建成功后生成下一份，失败保留输入，不使用所有用户共用的固定密码
- 用户在「我的」（`/portal/me`）输入当前密码和新密码即可改密；成功后退出全部 Portal 会话并提示重新登录，不影响 API Key 和订阅
- 独立迁移目录 `backend/crates/gateway-store/migrations/portal/`，冻结清单为同目录 `.frozen-sha256`
- 在线更新默认关闭；需要时设置 `CPR_ENABLE_UPDATES=true`
- 公网用户面板使用 HTTPS；反代部署须配置 `api.trusted_proxy_ips` 并正确维护 XFF，避免乘客共用代理 IP 的登录限流桶，见 [公网访问](../deploy/README.md#公网访问)
- 用户管理中的“开通 / 更换套餐”须确认目标套餐和绝对到期时间；更换默认保留仍有效的原到期时间。只有显式选择并确认“无到期”才提交 `endsAt: null`，空日期不可提交
- “续期”固定原套餐并保留开始时间，新到期时间必须晚于原到期时间及当前时间；输入按浏览器本地时区解释。无到期订阅不提供续期入口
- 开通、换套餐和续期仍调用现有 `subscriptions/assign` 设置绝对期限，事务内替换当前订阅；不自动累加购买时长，不重置用户已用额度
